# Agent Note: 云端候选皮肤清单与跨平台客户端对齐

Status: implemented

## Problem

跨平台客户端已接受 msime-windows 的 `canvas`、`wechat_scroll`、几何与九宫格清单，但服务端的 `ParseStored` 和种子脚本仍使用旧方言。社区上传即使只含合法 PNG 也被基底或引用集合拒绝，数据库目录也无法提供这类皮肤。

## Decision

以 msime 固定提交 `207a8c590bc1a3c06ff26348953d3495101ecc8d` 的共享扫描器为来源，同步共享用例表，移植新增字段的范围、类型、路径和版本规则。Go 与离线 SQL 种子脚本按同一份合成用例验证。清单原始字节继续保留；公开目录 JSON 的现有形状不增加绘制字段，社区引用校验使用仅在服务端保存的图片集合。

保留 ID 加入 `canvas`、`wechat_scroll`；数据库资源扩展名加入 `.apng`（媒体类型 `image/png`），配套迁移与 Ready 检查。旧行不回头校验，新写入受约束。社区上传增加 `resources=canvas-v1` 能力声明与 `X-MSIME-Candidate-Resources: canvas-v1` 响应头，不增加条目 JSON 字段。新客户端上传前须检查能力头；旧副本可能忽略查询参数，所以 200 本身不是支持证明。未协商时仍限三张 PNG/JPEG，列表在分页前排除扩展包，详情与下载返回 404，同步列表不返回扩展包。按文件数量和扩展名的存储事实过滤，不新增易漂移的能力版本列。

扩展包最多 37 张图片，覆盖预览、旧装饰、背景、两个九宫格来源与 32 个挂件。保留原有压缩字节、单边尺寸、预览与整包像素上限，新增 GIF/WebP 与 `.apng` 后缀；预览继续限定 PNG/JPEG。GIF 在解码前扫描帧边界，再完整解码重编码；WebP 用现有 `x/image/webp` 逐帧解码，清理 RIFF 元数据并保留原位流、帧时长、循环、处置与混合。所有动画逐帧按完整画布计费，先完成整包预检再解码。WebP 容器依据 [官方规范](https://developers.google.com/speed/webp/docs/riff_container)。社区文件路径约束配套幂等迁移与 Ready 检查。

只准备代码与 PR，不执行生产迁移或发布。

## Alternatives considered

- 只放行两个 base：代码最少，但无效几何会绕过客户端相同的校验，且九宫格和挂件仍被当作未引用资源拒绝，因此不用。
- 在目录 JSON 加入全部新绘制字段：客户端可不下载清单便开始绘制，但扩大了既有未协商响应格式；当前客户端仍读取原始清单，因此使用内部引用集合，保留公开形状。

- 直接全局放宽图片格式与数量：新版客户端实现简单，但旧客户端会因 `file_count > 3` 拒绝整页；因此使用独立能力声明与分页前过滤。
- 动画统一转成 PNG：无需容器适配，能复用现有编码器，但会丢失帧、时长和循环，违反上游皮肤兼容要求；因此保留动画。
- 新增 WebP 动画编解码依赖：可以少写容器处理，但现有依赖已能解码静态位流；只需按官方容器规范提取有界帧，无需增加原生依赖或再次有损编码。

## Testing

Go 和种子脚本共用固定来源的 240 条方言用例及新增的 123 条合成边界用例。PNG 画布包经过完整上传校验；遗漏资源和非生效引用拒绝。HTTP 回归覆盖发布、落库、下载后的重新解析；数据库回归覆盖旧约束升级、重复迁移和越界路径拒绝。全仓 race、vet、后台构建、契约与发布脚本检查通过。真实 PostgreSQL 17 + pgvector 的账号与服务端完整 race 测试通过，覆盖率门禁分别达到至少 85% 和 88%（远端验收 `20261019-180246`）；最终提交的画布 HTTP 往返、资源路径和保留 ID 迁移、Ready 顺序与同步主分支后的专项回归也通过（`20261019-182035`）。临时数据库均正常停止。

## Consequences

云端准备扩展资源协议和图片处理；共享客户端的能力探测、上传、下载、安装与同步仍需配套，不能只删除 `SERVER_UNSUPPORTED_BASES` 便声称已兼容。滚动升级期间写请求仍可能命中旧副本，客户端必须处理拒绝而不能无限重试。Linux 原生画布与各宿主动画渲染的设备证据由对应客户端改动承担，本次云端验收不代替它们。


本次检索活跃笔记中的 `canvas`、清单和候选皮肤机制，已有 QQ 公共工具与邮件指标笔记只涉及读取与统计；匿名下载笔记约束访问权限和事务，本次沿用并叠加资源协商，不改变匿名权限。清单与上传资源同属本篇，原地扩展。新的范围校验提高与共享扫描器的一致性，代价是 Go 与种子脚本仍各自实现校验，后续变化需继续以共享用例同步。
