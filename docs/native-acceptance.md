# 原生宿主验收

本清单用于共通后端开发版的最终平台验收。自动化服务类测试的结果不能代替这里的系统输入、录音权限、焦点和签名检查。所有输入使用下列合成数据；报告只记录结果，不包含设备令牌、供应商密钥或私人输入。

## 准备与证据

记录 Server、Engine 和平台源码的 commit（未提交时保存本任务补丁摘要），以及实际 Engine gitlink、构建配置、操作系统版本、测试时间。上游服务使用受控测试账户或合成响应；仅模拟响应的结果必须标为“合成上游”。不要把工作区中不匹配的 vendor 当作已验证发布输入。

准备可由测试设备访问且证书受信任的 HTTPS 服务地址。每台设备使用独立令牌。先通过 `GET /v1/capabilities` 核对要验收的能力已启用。服务的默认配置只开启云候选。流式语音另需启用 `streaming` 并允许反向代理转发 WebSocket Upgrade。

自动化基线：

```sh
pnpm --dir admin-web build
go test -race ./...
go vet ./...
python3 scripts/sync_contract.py --check
python3 scripts/native_e2e.py
# 在 macOS 同时检出 Apple 仓库时：
python3 scripts/apple_e2e.py
```

`native_e2e.py` 需要 Docker 与相邻 Windows/Linux 工作区；它在 Linux 编译客户端服务类。`apple_e2e.py` 使用真实 NSURLSession，但不进入 InputMethodKit 或键盘扩展。

## Windows

使用匹配 product-lock/Engine 的开发版，执行仓库既有 x86/x64 TSF 构建、Server 构建和真实词库测试。设置页标准构建的契约预检也必须通过。选择系统输入法，在普通文本编辑器中完成：

| 场景 | 操作 | 通过标准 |
|---|---|---|
| 云候选 | 配置后端云候选地址和设备令牌，输入 `nihao` | 本地候选可用；后端候选出现并可选择上屏 |
| 请求代次 | 输入后立即清空、改为另一个拼写，或切换编辑器 | 旧结果不会进入新组合或另一个应用 |
| 故障回退 | 使用错误设备令牌、暂停服务、恢复服务 | 输入不卡死；错误时本地候选可用；恢复后新请求可成功 |
| 配置隔离 | 将云候选地址改为第二个测试端点 | 旧令牌被清除；填写第二端点令牌后才恢复联网 |
| AI/翻译 | 按 Docs 后端指南配置自定义地址，触发联想及候选翻译 | 结果出现且可上屏，客户端使用设备令牌 |
| 批量语音 | 配置转写和润色地址，录入“今天测试输入法”，结束录音 | 正常转写、可选润色；录音和取消状态正确 |
| 实时语音 | 选择“MSIME 共通后端（实时语音）”，配置 WSS 地址与设备令牌 | 录音时持续显示识别结果；结束后提交最终结果；无需供应商密钥 |
| 实时取消/焦点 | 录音时取消、切换应用、锁屏，或在另一编辑器开始新会话 | 不向失焦窗口提交，不复用上一会话结果，不遗留录音 |
| 连接释放 | 活动实时会话期间关闭后端，再重新启动 | 客户端结束失败会话；下次录音可重新连接；服务正常退出 |

分别记录 x86 和 x64 宿主结果。MinGW 语法检查和 Linux 下的协议测试不计入这些运行结果。

## macOS InputMethodKit

使用匹配 Engine 的通用开发构建，在独立测试用户的输入源中启用输入法。设置共通后端，先输入 `nihao`，再验证候选合并、选择上屏和本地候选共存。分别执行取消组合、切换编辑器、切换输入源、重新打开设置、更换端点及错误令牌场景；旧异步结果不得进入新组合。

通过语音设置配置批量转写和润色，录入“今天测试输入法”，检查麦克风权限、结束、取消及焦点切换。共享 Voice 类的网络测试只证明协议链路，不证明 IMK 上屏和录音生命周期。

## iOS 签名设备

主 App 和键盘扩展必须使用同一开发团队及共享 Keychain entitlement，设备可安装对应签名的开发构建。

1. 在主 App 保存 HTTPS 地址和设备令牌；启用键盘，但关闭“允许完全访问”。输入 `nihao`：本地输入正常，后端不得收到键盘请求。
2. 打开完全访问并重新打开键盘：云候选出现，证明扩展能读取主 App 保存的共享凭据。
3. 清空组合、切换键盘、切换文本框：旧请求不再更新候选；重新打开键盘可发起新请求。
4. 在主 App 关闭后端，再重开键盘：后端无请求，本地输入正常。
5. 修改服务地址但不填写新端点的令牌：不复用原端点凭据。填写正确令牌后恢复。
6. 关闭完全访问、使用错误令牌或使服务不可达：输入仍可用。恢复权限/令牌/服务后，新会话可成功。

模拟器 SDK 编译和 Foundation 单进程测试不证明真机共享 Keychain 或完全访问门禁。当前 iOS 没有录音入口，不以录音作为 iOS 验收项。

每项填写 `通过 / 失败 / 未执行`，并附对应构建标识、环境、是否真实供应商、最短复现步骤和不含输入/密钥的结果证据。未执行项目保持未完成；远程 CI、生产部署、上游合并与消费者固定版本分别记录，不能由本地构建结果推断。
