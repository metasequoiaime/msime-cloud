# 后台社区按内容类型拆分入口

## 目标

将原「社区管理」的六种内容拆成侧栏「社区」分组下的六个独立页面：键盘皮肤、候选窗皮肤、插件、社区词库、回复模板、短语包。社区词库与既有词库管理入口使用不同名称。

## 结构与行为

每种内容拥有独立路由和页面包装组件，共用原有列表、详情、编辑、举报、审核和撤销逻辑。切换页面时卸载原页面的本地状态，防止旧列表或详情绑定到新类型；同类翻页仍保留上一页结果。现有权限及接口保持兼容。

侧栏和概览共用各类型待审核计数缓存。概览保留总数，并提供六个带待审核筛选的直达链接；审核完成后刷新计数。

## 旧入口兼容

保留 `/community`，默认跳转键盘皮肤。合法 `tab` 选择目标页面，带合法类型前缀的 `focus` 优先；普通作品 ID 不被误判成类型。跳转保留状态、可见性、页码及定位参数，移除旧 `tab`。搜索与通知继续兼容旧后端返回的 `community` 目标。

Go 静态处理器登记全部页面，支持刷新与直达。沿用已有视觉样式和移动端菜单。

## 验证

导航单元测试覆盖六入口与旧目标映射；Go 测试覆盖深链接；真实浏览器验证旧入口参数、搜索和通知详情、切页时挂起的列表请求、审核目标与计数刷新、同类翻页和移动端菜单。运行前端检查、完整 CSP 冒烟、契约检查及全仓 Go 检查。
